# Real Estate Agent Business Toolkit

A complete, ready-to-use operating system for real estate agents — listing presentation frameworks, CMA guides, open house sign-in sheets, client onboarding packets, lead follow-up systems, and a business management workbook.

## What's Inside

| File | Description |
|------|-------------|
| `book.md` | The complete toolkit guide — positioning, how each document works, the listing appointment process end-to-end, pricing psychology, follow-up discipline, and quarterly business review. (Source for the PDF version.) |
| `listing-presentation.md` | Fill-in template for winning listings: pre-listing prep checklist, comps analysis table, pricing scenarios, marketing plan, commission terms, 17 objection handlers, and close-the-listing script. |
| `cma-guide.md` | Comparative market analysis guide: pulling comps, adjustment factors, pricing strategy worksheet, net sheet, and listing appointment script. |
| `open-house-signin.md` | Printable open house sign-in sheet with TCPA/CAN-SPAM compliant consent language and agent contact footer. |
| `client-onboarding.md` | New client onboarding packet: welcome letter, document checklists (sellers & buyers), communication preferences form, timeline expectations, and "what to expect" guides. |
| `lead-followup.md` | Lead follow-up system: 5-3-1 cadence, 10 touchpoint message templates, sphere-of-influence scripts, and expired/cancelled/FSBO outreach scripts. |
| `Real-Estate-Agent-Toolkit.xlsx` | Spreadsheet companion with live formulas: CMA calculator ($/sqft analysis + suggested list price), commission/net calculator, lead tracker, open house log, and monthly goals. |

## How to Use

1. **Start with `book.md`** — read the guide to understand how the system fits together.
2. **Customize templates** — replace bracketed fields like `[Your Name]` and `[Brokerage]` with your information.
3. **Print as needed** — `open-house-signin.md` is designed for printing (see HTML comments for instructions).
4. **Use the xlsx workbook** — track leads, transactions, marketing spend, and run quarterly business reviews.
5. **Follow the cadence** — use `lead-followup.md` for consistent, systematic follow-up.
