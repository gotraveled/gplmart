# Providers - image generation

## fal.ai (primary for stills)

- FAL_KEY credential, image models: FLUX.1 [dev/schnell], Gemini 2.5 Flash Image, Ideogram
- Cost: ~$0.01-0.10 per image depending on model - cheap enough to iterate
- Best for: batch shot lists, fast iteration on rejects
- FLUX dev = best product fidelity; schnell = fastest/cheapest for drafts

## Higgsfield

- MCP connector, image + video models
- Use when user prefers one provider for both photos and video

## Workflow cost discipline

- Generate DRAFTS on cheap/fast model first (schnell/flash) - confirm composition
- Final hero shots on quality model (FLUX dev) - fidelity matters most there
- Typical shoot: 8-12 generations per product = under $1 total on fal.ai
- Show shot list + model + est. cost before batch
