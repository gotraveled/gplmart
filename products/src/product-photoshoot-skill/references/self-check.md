# Photoshoot self-check

- [ ] Product matches reference photo - shape, colour, label, proportions
- [ ] Label text correct or acceptably blurred - never wrong words
- [ ] Background matches request (pure white where required)
- [ ] Platform rules satisfied (Amazon main = white/no props/no text)
- [ ] Resolution sufficient (2000px+ for marketplace zoom)
- [ ] File names clear: product-hero-white.jpg etc.
- [ ] No watermarks, no AI-artifacts (extra fingers, warped edges, impossible shadows)
- [ ] Consistent style across the shoot (same lighting/bg logic)
- [ ] User approved each shot type before final delivery
