# Digital Product Empire Bundle

Six ready-to-sell digital product systems in one zip - profit spreadsheets, ad copy swipe file, social media content kit, resume/proposal kit and Shopify store documents, plus the launch guide.

## What's inside
This zip contains six product folders, each with its own README and files:

- `ecom-profit-pricing-system/` - profit & pricing workbook (.xlsx)
- `etsy-dropshipping-business-toolkit/` - Etsy business workbook (.xlsx)
- `ad-copy-swipe-file-vol1/` - ad copy swipe file (PDF + CSV + MD)
- `social-media-content-kit-vol1/` - social content kit (PDF + CSVs + MD)
- `resume-freelance-proposal-kit/` - resumes, proposals, cover letters + guide PDF
- `shopify-store-launch-doc-pack/` - store legal/business documents + email templates + guide PDF
- `digital-product-empire-bundle/` - bundle guide (book.pdf) + this README

## How to use
1. Unzip - each product has its own folder and README.
2. Read `book.pdf` first - it contains the 30-day launch plan and reselling guide.
3. Open the .xlsx files in Excel or Google Sheets (File > Import).
4. All products include resell rights - sell them as your own.
