# Sequence templates - ready-to-adapt copy

## Welcome series

**Email 1 (immediate)**: Order confirmation + delivery info + "what happens next" + brand intro (2-3 lines max)

**Email 2 (day 2)**: Value content - "3 ways to get the most from your [product]" or quick tip/guide. Soft product mention only.

**Email 3 (day 5)**: Social proof - 2-3 reviews/testimonials + "explore more" CTA. No hard sell.

## Abandoned cart

**Email 1 (1 hour)**: "You left something behind" + product image + single CTA back to cart. No guilt.

**Email 2 (24 hours)**: Objection handler - shipping time, returns policy, guarantee, FAQ snippet. "Questions? Reply here."

**Email 3 (48 hours)**: Final reminder + real urgency ONLY if true (stock running low, price ending). Otherwise: "Still thinking it over? Here's 10% off to help decide."

## Product launch

**Teaser (24h before)**: "Tomorrow: [product name] drops. Early access for subscribers."

**Launch day**: Hero image + product story (2-3 sentences) + offer + "Shop now" CTA + early-bird deadline if real.

**Follow-up (48h)**: Social proof + "last chance" only if offer actually expires.

## Win-back (90+ days inactive)

**Email 1**: "We noticed you've been away" + what's new since + one incentive (discount/free shipping). Single CTA.

**Email 2 (7 days later)**: Different angle - bestsellers, new arrivals, brand story. No repeat of first offer.

## Review request (post-delivery +7 days)

Short, grateful, single ask: "How's your [product] working? A quick review helps others find us."
