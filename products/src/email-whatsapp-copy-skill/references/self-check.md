# Pre-send checklist

## Email
- [ ] Subject line under 50 chars, no spam triggers
- [ ] Preview text continues the story
- [ ] One email = one purpose, one clear CTA
- [ ] Unsubscribe link present and working
- [ ] Sender name + address in footer
- [ ] Mobile preview tested (most opens are mobile)
- [ ] Links tested - every URL works
- [ ] Segment correct (not blasting everyone everything)

## WhatsApp
- [ ] Under 500 chars, or split into sequence
- [ ] Brand identified in first message
- [ ] Opt-in confirmed for every recipient
- [ ] Within 24h window OR using approved template
- [ ] STOP/opt-out honored immediately
- [ ] No links to unverified domains
- [ ] Sent via proper API/broadcast tool, not personal WhatsApp

## Both
- [ ] Offer/claims accurate and current
- [ ] No fake urgency (real deadlines only)
- [ ] Frequency within caps for this segment
- [ ] Timing appropriate for audience timezone
