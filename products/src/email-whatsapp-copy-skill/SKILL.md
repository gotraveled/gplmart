# Email & WhatsApp copy that gets opened and clicked

Two channels, two different games:

- **Email**: survives on subject lines + genuine value. People tolerate email if it respects them.
- **WhatsApp**: survives on being SHORT and feeling personal. Long messages get ignored or blocked.

This skill writes both - sequence structures, message copy, send timing and the compliance rules
that keep you out of spam folders and WhatsApp bans.

---

## Intake - one batch

1. Store/product + what you're selling
2. Which sequence? (welcome / abandoned cart / product launch / sale / win-back / review request)
3. Audience segment? (all customers / recent buyers / cart abandoners / VIPs)
4. The offer or hook (discount, newness, urgency)
5. Brand voice: friendly / premium / playful / urgent
6. Platform: Klaviyo / Mailchimp / Shopify Email / WhatsApp Business API / manual broadcast
7. Any compliance notes? (opt-in status, region - WhatsApp rules differ India vs elsewhere)

## The core sequences

### Welcome series (3 emails over 7 days)

| Day | Purpose | Content |
|---|---|---|
| 0 | Deliver + delight | Order confirmation + what happens next + brand story (short) |
| 2 | Value-first | How to use/get most from product + quick tip or guide |
| 5 | Social proof | Reviews/testimonials + soft CTA to explore more |

### Abandoned cart (3 emails over 48h)

| Timing | Angle |
|---|---|
| 1 hour | Reminder + product image + "still thinking?" |
| 24 hours | Objection handler - FAQ, shipping, returns, guarantee |
| 48 hours | Urgency - stock/price/offer deadline (only if real) |

### Product launch (1 email + WhatsApp)

- Teaser (24h before): "something new drops tomorrow"
- Launch day: product hero + offer + early access for subscribers
- Follow-up (48h): social proof + last chance if offer expires

### Win-back (dormant customers)

- "We miss you" + what's new + incentive (only if margin allows)
- Segment: 90+ days inactive, exclude recent openers/non-openers separately

## WhatsApp rules (India especially)

- **Opt-in required**: WhatsApp Business API bans unsolicited broadcasts. Only message people who gave permission.
- **24-hour window**: free-form messages only within 24h of user's last message. Outside that = template messages (pre-approved).
- **Length**: under 500 characters per message. Break longer content into 2-3 short messages.
- **Formatting**: *bold*, _italic_, ```monospace``` work. No markdown headers/lists.
- **Frequency**: max 2-3 broadcasts/week. More = blocks.
- **First message**: always identify the brand - "Hi, it's [Store] here..."
- **STOP keyword**: honor immediately, no exceptions

## Copy rules

**Email subject lines**:
- Under 50 chars for mobile preview
- Curiosity > clickbait - "Your order shipped" beats "You won't believe..."
- Personalize where possible (name, product, city)
- A/B test: question vs statement vs number

**Email body**:
- One email = one purpose. Never sell AND educate AND request review in one message.
- First 2 lines visible in preview - make them count
- Scannable: short paragraphs, bold key points, one clear CTA button
- Plain text > heavy HTML for deliverability

**WhatsApp**:
- Sound like a person, not a brand - "Hey! Check this out" > "Dear valued customer"
- Emojis: 1-2 max, relevant not decorative
- One message = one thing. Link at the end.
- Never send walls of text - if it needs scrolling, split it

## Compliance

- CAN-SPAM/GDPR: unsubscribe link in every email, honor within 10 days
- WhatsApp: opt-in proof required, template approval for outside-24h messages
- India DPDP Act: consent-based messaging, data minimization
- Never buy email/WhatsApp lists - one spam complaint can kill your sender reputation
