# Bundle audit checklist

## Before creating bundles

- [ ] Products identified (what to bundle, why)
- [ ] Bundle type chosen (pure/mixed/quantity/gift/mystery/seasonal)
- [ ] Bundle price calculated (discount depth appropriate)
- [ ] Margin verified (bundle margin meets minimum target)
- [ ] Bundle contents clear (customer understands what's included)
- [ ] Images ready (show all items in bundle)

## Bundle setup

- [ ] Bundle product created on platform
- [ ] Component products linked correctly
- [ ] Inventory syncs properly
- [ ] Bundle price displayed clearly
- [ ] Savings callout visible ("Save ₹X" or "X% off")
- [ ] Bundle description explains value

## Promotion

- [ ] Homepage banner/collection featuring bundles
- [ ] Product page "frequently bought together" section
- [ ] Cart page upsell for complementary products
- [ ] Email/WhatsApp broadcast planned
- [ ] Ad creatives created (if running ads)
- [ ] Social media posts scheduled

## Performance tracking

- [ ] Bundle sales tracked separately
- [ ] Bundle AOV vs single AOV monitored
- [ ] Bundle margin calculated
- [ ] Bundle conversion rate tracked
- [ ] Underperforming bundles identified for removal

## Optimization

- [ ] Bundle prices tested (10% vs 15% vs 20%)
- [ ] Bundle compositions tested (which products work?)
- [ ] Seasonal bundles refreshed
- [ ] Winning bundles promoted harder
- [ ] Losing bundles killed or adjusted

## Red flags

- [ ] Bundle margin <30% (unsustainable)
- [ ] Bundle conversion <1% (nobody wants it)
- [ ] Bundle AOV not higher than single (not achieving goal)
- [ ] Too many bundle options (decision paralysis)
- [ ] Bundles not promoted (created but invisible)
