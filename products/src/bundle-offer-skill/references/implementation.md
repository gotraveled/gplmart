# Implementation - platform setup guides

## Shopify

### Option 1: Shopify Bundles app (free)

1. Install "Bundles" app from Shopify App Store
2. Create bundle product in admin
3. Select component products
4. Set bundle price (auto-calculates savings)
5. Inventory syncs automatically

**Best for**: Simple fixed bundles (product A + B + C at set price)

### Option 2: Bold Bundles / Bundle Bear apps

1. Install bundle app
2. Create bundle with multiple options (mix-and-match)
3. Set quantity breaks
4. Add "frequently bought together" recommendations
5. A/B test bundle offers

**Best for**: Complex bundles, quantity breaks, upsells

### Option 3: Manual bundle products

1. Create single product "Skincare Routine Bundle"
2. Add images showing all items
3. Set bundle price manually
4. List what's included in description
5. Track bundle sales separately

**Best for**: Simple fixed bundles, full control

### Quantity breaks

1. Install "Quantity Breaks" or "Volume Discount" app
2. Set tiers: Buy 1 = ₹499, Buy 2 = ₹899, Buy 3 = ₹1,199
3. Display tiers on product page
4. Automatic discount applies at checkout

## Marketplaces (Amazon/Flipkart/Meesho)

### Amazon
- Create "Virtual Bundle" in Seller Central
- List component ASINs
- Set bundle price (must be lower than buying separately)
- Use "Frequently bought together" for cross-sells

### Flipkart
- Create combo products in seller dashboard
- Set combo pricing
- Use "Complete the look" features

### Meesho
- Create bundle listings
- Focus on value bundles (higher margin for resellers)
- WhatsApp/catalog sharing angle

## Gift with purchase

### Shopify
1. Install "Gift with Purchase" app
2. Set rule: orders over ₹999 get free [gift]
3. Auto-add gift to cart or show as option
4. Track redemption rate

### Manual
1. Create discount code "FREEGIFT"
2. Add free item to order manually
3. Or bundle gift with main product at same price
