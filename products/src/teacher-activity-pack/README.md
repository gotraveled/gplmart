# The Teacher Activity Pack

Print-and-go classroom activities for grades K-5: 3 word searches, 3 math drill sheets, handwriting practice pages and a reward chart.

## What's inside
- **Teacher-Activity-Pack.pdf**:
  - 3 word searches (school, space, garden themes) with word lists
  - Addition, subtraction and multiplication drill sheets (20 problems each)
  - 2 handwriting practice pages with letter guides
  - Classroom reward chart with 5 behavior tracks

## How to use
Print at 100% / Actual Size. Word searches and drills are single-page; handwriting pages work single or double-sided.
