# The Life OS Kit

A complete personal life operating system as Markdown files — goals, projects, habits, finance, reading, journal, and a personal CRM, all linked together. A Notion-template alternative you fully own. Works in Notion, Obsidian, Google Docs, or on paper.

## What's inside

| File | What it does |
|------|--------------|
| `book.md` | The guide: what a Life OS is, setup in under an hour, the weekly review ritual, troubleshooting, and a 30-day launch plan. |
| `dashboard.md` | Command center — links to all areas, this week's focus, quick stats, inbox, coming-up dates. |
| `goals.md` | Yearly → quarterly → monthly goals framework with a goal-setting worksheet and someday/maybe list. |
| `weekly-review.md` | Friday review template — wins, misses, metrics, projects check, next week's focus. |
| `habits.md` | 3-5 habit tracker on a 31-day monthly grid with month-end stats and retro questions. |
| `finance.md` | Monthly budget — income, fixed/variable/sinking-fund expenses, savings/debt, formulas in text. |
| `projects.md` | Project tracker — status, one next action per project, waiting-on list, paused/completed/someday sections. |
| `reading-library.md` | Reading queue, currently-reading notes, book-notes template, yearly reading log. |
| `journal.md` | Daily journal template with prompts (morning, evening, weekly, gratitude). |
| `contacts-crm.md` | Personal CRM — inner circle / friends / extended tiers, key dates, monthly review questions. |

## How to use

1. Pick a platform: **Notion** (paste each `.md` into a page — Markdown pastes natively), **Obsidian** (drop files into a folder, `[[links]]` work out of the box), **Google Docs** (one doc per file), or **print** (habits and finance print cleanly).
2. Read `book.md` first — it walks through the full setup in under an hour.
3. Start small: the 30-day launch plan in `book.md` phases in the files week by week.
4. The weekly review (`weekly-review.md`) is the engine — everything else feeds it.

## Notes

- All files use `[BRACKETED]` placeholders and worked examples — fill them in, don't delete them.
- `[[wikilink]]`-style links work natively in Obsidian and Notion; in Google Docs treat them as plain text references.
- Modify freely — the system is meant to be edited until it fits your life.
