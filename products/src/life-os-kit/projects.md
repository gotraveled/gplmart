## 🚦 PROJECT RULES

1. **3-5 active max.** New project? Pause or complete one first.
2. **Every project has ONE next action.** No next action = stalled = decide: reschedule, delegate, or kill.
3. **Weekly review updates this file.** If you didn't touch it in the review, it's not real.
4. **"Waiting on" is a first-class status.** External blockers need follow-up dates, not vague hope.
5. **Projects serve goals.** If a project doesn't connect to [[goals]], ask if it should exist.
