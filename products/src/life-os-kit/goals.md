## 📝 GOAL-SETTING WORKSHEET (for new goals)

Copy this block for each new goal:

```
GOAL: [Specific, measurable outcome]
WHY: [The real motivation — write the honest one]
AREA: [Health / Money / Career / Learning / Relationships / Creative]
TIMEFRAME: [When — date, not "someday"]
FIRST STEP: [The smallest action you can take THIS WEEK]
WEEKLY CHECK-IN: [How you'll measure progress]
OBSTACLE PREDICTION: [What will probably derail this?]
PLAN B: [If the obstacle happens, what instead?]
```

**EXAMPLE:**
```
GOAL: Save $12,000 by December 31
WHY: House deposit + peace of mind
AREA: Money
TIMEFRAME: Dec 31
FIRST STEP: Set up auto-transfer of $300/paycheck this Friday
WEEKLY CHECK-IN: Sunday — check savings balance vs. monthly target
OBSTACLE PREDICTION: Unexpected car repair / holiday spending
PLAN B: Pause restaurant budget, not the auto-transfer
```

## 🔄 MONTHLY REVIEW QUESTIONS

At the end of each month, answer in [[weekly-review]] or here:

1. Which monthly goals did I complete? Which slipped — why?
2. Which yearly goal needs more/less attention next month?
3. Is there a goal I should DROP? (Dropping is allowed — decide consciously.)
4. What's ONE thing to change next month based on this month's data?
