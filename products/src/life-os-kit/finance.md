## 🧮 THE MATH (formulas in text)

```
Total Budgeted = TOTAL INCOME
Total Spent     = TOTAL FIXED + TOTAL VARIABLE + TOTAL SINKING + TOTAL SAVINGS/DEBT

Remaining = TOTAL INCOME − (FIXED actual + VARIABLE actual + SINKING actual + SAVINGS actual)

If Remaining < 0: you're spending more than you earn → cut VARIABLE expenses first.

Savings Rate = (TOTAL SAVINGS/DEBT actual) ÷ TOTAL INCOME actual
Target: ≥ 20%. Below 10%? Red flag — see goals.

Per-day discretionary = (Dining + Entertainment + Shopping actual) ÷ days in month
Use this to spot "where did the money go" weeks.
```
