# Platform copy rules

## Amazon
- Title: no promotional text ("best", "free shipping"), no ALL CAPS, no symbols (!*?)
- Bullets: 5 max, benefit-led, ~500 chars each
- Description: plain text converts better than HTML on Amazon
- Backend keywords: separate field, don't repeat title words
- Variations: use parent-child correctly or lose the variation family

## Flipkart
- Title shorter than Amazon - punchy, keyword-front
- Bullets: 5-8 allowed, keep scannable
- Emphasize Flipkart-specific: exchange offer, EMI, plus subscription
- Images matter more than copy on Flipkart - listings live/die on photos

## Meesho
- Audience = resellers + value buyers - mention margin/resale potential
- Shorter copy, mobile-first formatting
- WhatsApp/catalog sharing angle resonates
- Price sensitivity highest here - value framing over premium

## Shopify (own store)
- No character limits - write for conversion not algorithm
- Use metafields for structured specs (size guides, care instructions)
- Product description = brand voice showcase - storytelling welcome
- SEO title/meta separate from display title

## Universal
- Spell check everything - typos kill trust
- Consistent units (grams not "g", cm not "centimeters")
- Include care/washing instructions where relevant
