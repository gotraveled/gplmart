# Pre-publish checklist

## Accuracy
- [ ] Every spec verified against real product/supplier sheet
- [ ] No invented materials, dimensions, or certifications
- [ ] Warranty/return terms match actual policy
- [ ] Price/offer claims match reality

## Copy quality
- [ ] Title under platform limit, keywords front-loaded
- [ ] Bullets benefit-first, one idea each
- [ ] Description answers: what, why, who, how, specs, FAQ
- [ ] Keywords natural, no stuffing, no competitor trademarks
- [ ] Spell check + grammar pass done

## Platform fit
- [ ] Amazon rules: no promo text in title, 5 bullets max
- [ ] Flipkart: title under 150 chars
- [ ] Meesho: value/reseller angle included
- [ ] Shopify: metafields/SEO fields filled

## Conversion
- [ ] Hook addresses real buyer pain, not generic intro
- [ ] Social proof element somewhere (reviews, numbers, awards)
- [ ] Clear CTA implied (buy now, add to cart, enquiry)
- [ ] Mobile-readable: short paragraphs, scannable bullets
