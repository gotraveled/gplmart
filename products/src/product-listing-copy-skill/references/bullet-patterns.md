# Bullet point patterns

## The formula

```
[Verb/benefit] + [specific feature] + [why it matters]
```

Bad: "Made of stainless steel"  
Good: "Keeps food hot 5+ hours - triple-layer stainless steel insulation"

## Category patterns

**Food/grocery**: taste/texture + ingredients + quantity + occasion  
**Fashion**: fit + fabric + occasion + care  
**Electronics**: spec + use case + battery/connectivity + warranty  
**Beauty**: concern + ingredient % + result + size  
**Home/kitchen**: function + material + capacity + convenience

## Bullet length

Amazon: ~500 chars max but front-load first 150 chars (mobile truncates)  
Shopify/Flipkart: 80-150 chars ideal - scannable

## Symbols

✓ or • at start - consistent across all bullets. Never mix.

## Common mistakes

- Feature-speak: "Equipped with 5000mAh battery" → "Lasts 2 full days - 5000mAh battery"
- Repeating title info - bullets add NEW info, not echo
- Wall of text - each bullet ONE idea
