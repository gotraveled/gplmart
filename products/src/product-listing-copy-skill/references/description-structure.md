# Description structure (long-form)

## Template

```
[HOOK - 2-3 sentences: the problem this solves, written for the buyer]

WHY [PRODUCT] - [3-4 expanded features with context]

PERFECT FOR: [use cases - who, when, where]

SPECIFICATIONS:
| Spec | Value |
(material, dimensions, weight, warranty, etc.)

[TRUST: warranty, certifications, what's in box]

FAQ:
Q: [real buyer question]? A: [honest answer]
(3-5 FAQs)
```

## Writing rules

- Hook = empathy first, product second ("Tired of X?" not "Introducing Y")
- Specs in table format - buyers scan, don't read
- FAQ answers real objections ("will it fit?", "is it durable?", "what's the warranty?")
- No keyword stuffing - write for humans, search engines follow
- Indian marketplaces: mention COD availability, EMI options if applicable

## Length guide

- Amazon: 1500-2500 chars (rich content helps)
- Flipkart: 1000-1500 chars
- Meesho: 500-800 chars (shorter converts better there)
- Shopify: as long as it stays scannable - use headers/bullets
