# Title formulas + platform limits

## Universal formula

```
[Brand] [Product Type] [Key Feature] [Size/Variant] [Use Case/Benefit]
```

## Category examples

**Kitchen**: "Borosil Glass Storage Container Set 5pc Airtight Lunch"  
**Fashion**: "Women Cotton Straight Kurti Printed Daily Wear M"  
**Electronics**: "Boat Airdopes 141 TWS Earbuds 42H Playback ENC"  
**Beauty**: "Minimalist Vitamin C Serum 10% Face Glow 30ml"  
**Home**: "Warmely Memory Foam Pillow Cervical Neck Support"  
**Grocery**: "Fortune Dark Chocolate Fills 500g Gift Pack"

## Platform character limits

- Amazon: 200 chars max title, 500 chars/bullet, 2000 chars description
- Flipkart: 150 chars title
- Meesho: ~100 chars title (resellers rewrite anyway)
- Shopify: no hard limit but SEO best practice <60 chars for title tag

## Title dos/don'ts

DO: front-load keywords, include differentiating spec, write naturally  
DON'T: ALL CAPS words, "FREE SHIPPING" in title, punctuation spam (!!!, ---), keyword stuffing
