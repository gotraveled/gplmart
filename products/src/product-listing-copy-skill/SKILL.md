# Product listing copy that sells

A listing has one job: answer "should I buy this?" in 5 seconds. This skill writes titles, bullet
points, descriptions and backend keywords that are accurate, benefit-led and platform-appropriate.

Works for any product category, any marketplace. Output = ready-to-paste copy, not advice.

---

## Intake - one batch

1. Product name + what it physically is
2. Category + target buyer (who, what they care about)
3. Platforms? (Shopify / Amazon / Flipkart / Meesho - pick all that apply)
4. Key features/specs (from supplier sheet or product)
5. Top 3 benefits in buyer language (not feature-speak)
6. Price point + any offer (EMI, combo, free shipping)
7. Compliance constraints? (health/finance/kids = careful wording)

## The listing anatomy

### Title formula

```
[Brand] [Product Type] [Key Feature/Material] [Size/Count] [Use Case]
Example: "Hiso HR Steel Lunch Box 3-Tier 1000ml Office tiffin"
```

- Front-load searchable keywords (marketplaces weight title heavily)
- Include variant-defining specs (size, count, material, colour)
- Stay under platform limits (Amazon ~200 chars, Flipkart ~150, Meesho shorter)
- No ALL CAPS, no promotional text in title (Amazon penalizes)

### Bullet points (5 max, benefit-first)

```
✓ [Benefit-led]: "Keeps food hot for 5 hours - stainless steel insulation"
✓ [Feature with use]: "3 leak-proof compartments for roti, sabzi, rice"
✓ [Trust signal]: "BPA-free, food-grade stainless steel, rust-proof"
✓ [Convenience]: "Lightweight 450g - easy to carry daily"
✓ [Offer]: "Comes with free lunch bag + spoons"
```

Rules: start with the BENEFIT, add the PROOF in same line. Never write "this product is made of X"
without saying WHY that matters.

### Description (long-form)

Structure:
1. Hook: the core problem this solves (2-3 sentences)
2. Features expanded: each bullet with more detail
3. Use cases: who/when/how (office, school, travel, gifting)
4. Specs table: dimensions, weight, material, care instructions
5. Trust: warranty, certifications, return policy, brand story (1-2 lines)
6. FAQ: 3-5 real buyer questions answered

### Backend keywords (invisible but searchable)

- Synonyms buyers actually type: "tiffin" + "lunch box" + "dabba"
- Misspellings common in search (marketplaces auto-correct poorly)
- Competitor alternative names (if legally usable - generic terms only)
- Regional language terms for Indian marketplaces

## Platform differences

| Platform | Title length | Bullets | Description | Keyword field |
|---|---|---|---|---|
| Amazon | ~200 chars | 5 x 500 chars | ~2000 chars | backend keywords |
| Flipkart | ~150 chars | 5-8 bullets | ~1500 chars | auto-indexed |
| Meesho | ~100 chars | 5 bullets | ~800 chars | reseller-focused |
| Shopify | flexible | metafields | rich text | tags + SEO fields |

## Rules

- NEVER invent specs - if you don't know the material, ask or write "premium quality" not a guess
- No superlatives without proof: "best", "#1", "world's finest" = ad/marketplace violations
- Health/beauty: no medical claims, use "supports/helps/promotes"
- Write for the BUYER's vocabulary, not manufacturer spec-speak
- Every claim must survive a "prove it" challenge
