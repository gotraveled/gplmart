# Shopify Store-in-a-Box

Everything a new Shopify store needs on day one: legal documents, profit spreadsheets, ad copy, social content and freelance tools - one zip, one launch system.

## What's inside
This zip contains five product folders plus the bundle guide:

- `shopify-store-launch-doc-pack/` - policies, FAQ, email templates + guide PDF
- `ecom-profit-pricing-system/` - profit & pricing workbook (.xlsx)
- `social-media-content-kit-vol1/` - captions, hooks, hashtags, calendar + guide PDF
- `ad-copy-swipe-file-vol1/` - ad copy swipe file (PDF + CSV + MD)
- `resume-freelance-proposal-kit/` - resumes, proposals, cover letters + guide PDF
- `shopify-store-in-a-box/` - bundle guide (book.pdf) + this README

## How to use
1. Unzip - each product has its own folder.
2. Read `book.pdf` - it has the 14-day launch plan.
3. Fill [BRACKET] placeholders with your store details.
4. All products include resell rights.
