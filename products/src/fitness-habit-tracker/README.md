# The Fitness Habit Tracker

Printable habit-tracking system: monthly habit grids, weekly reviews, streak tracking and SMART goal setting - designed to build habits that last.

## What's inside
- **Fitness-Habit-Tracker.pdf**:
  - How-to guide + habit design rules
  - 4 monthly habit grid pages (6 habits x 31 days + weekly totals)
  - 4 weekly review pages with habit score trackers
  - Goal-setting worksheet + emergency reset page

## How to use
Print the monthly grid each month, weekly review every Sunday. Mark X daily - streaks over perfection.
