# Review system audit checklist

## Collection system

- [ ] Review request emails/WhatsApp set up and active
- [ ] Timing appropriate for product type (7-10 days consumables, 14-21 days durables)
- [ ] Review links working and easy to access
- [ ] Packaging QR code included (if applicable)
- [ ] Review app/platform installed and configured
- [ ] Incentive strategy decided (if any) - disclosed properly

## Review quality

- [ ] Asking specific questions (not just "leave a review")
- [ ] Photo/video reviews encouraged
- [ ] Detailed reviews prompted ("what did you like most?")
- [ ] No rating-specific incentives (review manipulation)
- [ ] No fake/botted reviews

## Review management

- [ ] Responding to positive reviews within 24-48 hours
- [ ] Responding to negative reviews professionally
- [ ] Taking negative review conversations offline
- [ ] Tracking review sentiment trends
- [ ] Addressing product issues flagged in reviews

## Platform compliance

- [ ] Amazon: no incentivized reviews (Vine only)
- [ ] Shopify: incentives disclosed if offered
- [ ] Marketplaces: seller policies followed
- [ ] No review gating (showing only positive reviews)
- [ ] No review manipulation (friends/family, bought reviews)

## Metrics tracking

- [ ] Review count tracked by product
- [ ] Average rating monitored
- [ ] Review response rate tracked
- [ ] Review-to-sale conversion impact measured
- [ ] Negative review resolution rate tracked

## Red flags

- [ ] Review count stagnant (<1 new review/week for active store)
- [ ] Average rating dropping without product changes
- [ ] Multiple negative reviews same issue (product problem)
- [ ] Reviews not being requested (no system in place)
- [ ] Incentivized reviews without disclosure
