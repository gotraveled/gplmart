# Platform setup - Shopify, Amazon, marketplaces

## Shopify

### Review apps (recommended)

| App | Free plan | Best for | Features |
|---|---|---|---|
| Judge.me | Yes (unlimited reviews) | Most stores | Photo reviews, Q&A, email requests |
| Loox | No (free trial) | Photo/video focus | Instagram integration, video reviews |
| Okendo | No | Reviews + loyalty | Reviews, surveys, loyalty points |
| Stamped.io | Yes (limited) | Reviews + referrals | Reviews, loyalty, referral program |

### Setup steps (Judge.me example)
1. Install app from Shopify App Store
2. Customize review widget appearance
3. Set up automated email requests (timing, template, incentive)
4. Import existing reviews (if migrating)
5. Add review schema to product pages (for SEO rich snippets)

### Automated requests
- Trigger: X days after order marked "delivered"
- Channel: email (primary), SMS/WhatsApp (if available)
- Template: customize with your brand voice
- Incentive: optional discount code or loyalty points

## Amazon

### Vine program (early reviews)
- Amazon's official early reviewer program
- You provide free product, Vine reviewers post honest reviews
- Cost: product cost only (no fees)
- Best for: new products needing initial reviews

### Request a Review button
- In Seller Central, automated request to buyers
- Amazon sends the email (you don't control timing/copy)
- No incentives allowed
- One request per order

### What NOT to do
- No incentivized reviews (banned, account suspension)
- No review manipulation (asking friends/family)
- No review gating (only showing positive reviews)

## Flipkart/Meesho

- Reviews built into product pages
- Sellers can request reviews post-delivery
- Incentive policies vary - check seller guidelines
- Focus on genuine customer experience

## Google reviews (for local/business)

- Google Business Profile review requests
- QR code on packaging → Google review link
- Incentives allowed but must disclose
- Respond to all reviews (positive and negative)
