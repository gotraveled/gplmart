# Timing triggers - when to ask for reviews

## Post-delivery timing by product type

| Product type | Days after delivery | Reasoning |
|---|---|---|
| Consumables (food, beauty, supplements) | 7-14 | Enough time to use, still fresh experience |
| Fashion/apparel | 3-7 | Fit assessment done, still excited/unboxing energy |
| Electronics/durables | 14-21 | Used enough to form real opinion |
| Home/kitchen | 7-10 | Used in daily routine, visible results |
| Books/media | 3-5 | Read/started consuming |
| B2B/wholesale | 21-30 | Longer evaluation cycle |

## Trigger events (better than time-based)

### Order delivered
- Best trigger for most products
- Confirms customer received product
- Can segment by product type for timing

### Product-specific milestones
- **First use**: for apps/software, trigger after first login/use
- **Milestone reached**: for fitness products, after X workouts
- **Repurchase window**: for consumables, ask for review before next expected reorder

### Engagement-based
- Customer opened 3+ emails → engaged, more likely to review
- Customer visited product page 5+ times → high interest
- Customer added to wishlist → soft review request

## Frequency rules

- **Max 3 requests** per customer per product (initial + 2 follow-ups)
- **Wait 7+ days** between requests
- **Stop after review submitted** - don't ask again for same product
- **Cross-sell reviews**: can ask for review on different product later

## Segment-based timing

- **VIP customers** (5+ purchases): ask earlier, more personal tone
- **First-time buyers**: wait longer (need more confidence building)
- **Repeat buyers**: ask more readily (already trust you)
- **High-AOV customers**: personal WhatsApp message works better than automated email
