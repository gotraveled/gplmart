# The Party Game Bundle

Everything a host needs with zero prep stress: 30 unique bingo cards, caller sheets, Would You Rather cards, trivia, scavenger hunts, baby shower games and printable party signs.

## What's inside
- **Party-Game-Bundle.pdf** - ~45 pages:
  - 30 randomized bingo cards + 10 caller sheets
  - 30 Would You Rather cards (3 sets)
  - 40 trivia questions with answers (2 sets)
  - 3 scavenger hunts (birthday, baby shower, house party)
  - Baby shower games (guess the baby food, nursery rhyme quiz, advice cards)
  - 6 printable party signs

## How to use
Print at 100% / Actual Size. Bingo cards can be double-sided; signs look best on card stock.
