# Ad Copy Swipe File Vol. 1

A paid swipe file of 200+ ready-to-use ad copy templates — hooks, headlines, descriptions, CTAs, and angle formulas for Meta, Google, and TikTok ads.

## What's Inside

- `book.md` — The full swipe file as a markdown document (used to generate the PDF). Organized by platform and intent, with `[PRODUCT]`, `[AUDIENCE]`, `[OFFER]` style placeholders you swap for your specifics.
- `hooks.csv` — 200+ rows of short, punchy swipe lines in `category,platform,hook` format. Import into a spreadsheet or swipe file manager.
- `book.pdf` — Generated PDF version (built via `node scripts/md-to-pdf.mjs`).

## How to Use

1. Pick a hook that matches your product's angle (pain, benefit, curiosity, social proof, urgency).
2. Swap the bracketed placeholders with your product details.
3. Test 3-5 variants — never run just one ad.
4. Keep the winners and file them in your own swipe file.

Works for ecommerce, SaaS, courses, and service businesses — every swipe line is written to be adapted, not copied verbatim.
