# The Meal Planner & Grocery Bundle

4 weekly meal plan templates, a store-section grocery list and a budget tracker - eat well without the mental load.

## What's inside
- **Meal-Planner-Grocery-Bundle.pdf**:
  - How-to guide + budget targets
  - 4 weekly meal plan grids (breakfast/lunch/dinner/snack x 7 days)
  - Grocery list template organized by store section
  - Grocery budget tracker with category totals

## How to use
Print the weekly template you like, fill meals, shop once per week top-to-bottom. Track spend in the budget page.
