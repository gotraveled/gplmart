# The ADHD-Friendly Daily Planner

14 undated daily pages built for ADHD brains: energy check, top-3-only priorities, time blocks, body-double pomodoro timer and a shutdown ritual - plus a weekly reset and an overwhelm page.

## What's inside
- **ADHD-Daily-Planner.pdf** - how-it-works guide, 14 daily pages, weekly review, overwhelm reset page.

## How to use
Print the daily pages back-to-back and keep them in a binder or folder. Date is optional - the pages are undated so missed days don't break the system.
