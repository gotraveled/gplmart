# ROI tracking - attribution methods

## Unique discount codes (simplest)

Give each creator a unique code:
- PRIYA15 = 15% off for Priya's audience
- RAJU10 = 10% off for Raju's audience

Track: which codes get used, how many times, revenue generated.

**Pros**: dead simple, works everywhere  
**Cons**: only tracks purchases with code, misses organic influence

## UTM-tracked links

Unique link per creator per platform:
```
gplmart.com/product?utm_source=instagram&utm_medium=influencer&utm_campaign=diwali_launch&utm_content=priya_reel
```

Track in Google Analytics / Shopify analytics:
- Sessions from each creator
- Conversion rate per creator
- Revenue per creator

**Pros**: tracks all clicks, not just coded purchases  
**Cons**: requires analytics setup, cookie-dependent

## Affiliate links (best for ongoing)

Tools: Refersion, GoAffPro, UpPromote (Shopify apps)

- Unique link per creator → automatic tracking
- Commission auto-calculated on sale
- Dashboard shows clicks, conversions, earnings

**Pros**: automated, scalable, creators see their own stats  
**Cons**: monthly fee for tools, setup time

## Post-campaign survey

"How did you hear about us?" at checkout or in follow-up email.

Add "Instagram influencer" or "creator recommendation" as options.

**Pros**: captures word-of-mouth influence  
**Cons**: self-reported, can be inaccurate

## ROI calculation

```
Total campaign cost = creator fees + product costs + shipping + your time
Revenue = sales attributed to codes/UTM/affiliate links
ROI = (Revenue - Cost) / Cost x 100

Example:
- 5 micro creators x ₹5,000 fee = ₹25,000
- Product costs (5 x ₹500) = ₹2,500
- Total cost = ₹27,500
- Revenue tracked = ₹85,000
- ROI = (85,000 - 27,500) / 27,500 = 209%
```

## What "good" looks like

| Campaign type | Good ROI | Great ROI |
|---|---|---|
| Product launch | 100-200% | 300%+ |
| Ongoing affiliate | 150-300% | 500%+ |
| Brand awareness | Hard to measure | Track branded search lift |
| UGC for ads | Measure content performance | ROAS on ads using their content |

## Attribution challenges (be honest)

- Customer sees influencer post, buys 3 days later without code = unattributed
- Multiple influencers in funnel = who gets credit?
- Brand lift from awareness campaigns = hard to isolate

Solution: use multiple methods (codes + UTM + survey) and accept some uncertainty.
