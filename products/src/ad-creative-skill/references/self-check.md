# Pre-launch checklist

## Copy
- [ ] Hook works without the image (first line alone stops scroll)
- [ ] Every claim is verifiable or verbatim from product page
- [ ] No banned-category language (check compliance.md)
- [ ] Character counts fit the placement (125 feed / 40 stories / 40 headline)
- [ ] One idea per ad - no claim stacking
- [ ] CTA button matches the offer ("Get Offer" needs an actual offer)

## Creative brief
- [ ] Executable by a stranger (specific shots, not vibes)
- [ ] Text overlay words specified exactly
- [ ] End card includes logo + URL
- [ ] Safe zones respected for Stories/Reels UI

## Test structure
- [ ] 3 angles minimum, different hook styles
- [ ] Naming convention followed
- [ ] Budget split defined
- [ ] Kill criteria decided BEFORE launch ($150/0 sales)
- [ ] Tracking verified (pixel firing, events logging)

## Compliance
- [ ] Category rules checked (health/finance/kids = extra care)
- [ ] No fake urgency/scarcity
- [ ] Earnings/pricing claims defensible
