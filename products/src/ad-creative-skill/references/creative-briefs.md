# Creative briefs - direction designers/generators can execute

A creative brief is NOT "make it pretty" - it's a shot-by-shot or element-by-element spec.

## Brief template

```
FORMAT: [9:16 video / 1:1 image / 4:5 feed]
HOOK SHOT (0-3s): [exact visual - e.g., "hand holding product, text overlay 'POV:']
BODY: [what happens - e.g., "product in use, 3 quick cuts of features"]
TEXT OVERLAYS: [exact words + placement - e.g., "'Tired of X?' top third, bold white"]
END CARD: [logo + CTA + URL]
MOOD: [lighting, pace, colour treatment]
MUST-NOTS: [no face, no stock footage feel, no cluttered bg]
```

## For image ads

```
SUBJECT: [product, exact appearance]
SCENE: [background/context]
LIGHTING: [natural/studio/dramatic]
TEXT SPACE: [where copy goes - clean area needed]
STYLE: [lifestyle/editorial/minimal/bold]
```

## For video ads (pairs with the video skills)

Reference the shot grammar from the video skill products - hook in first 1.5s, hard cuts,
text cards <=6 words, end card with logo+URL.

## The test: could a stranger execute this?

If the brief says "make it engaging" - it's useless. If it says "0-3s: extreme close-up of
water droplets on the bottle, slow push-in, text 'Hydration in a sip'" - it's executable.
