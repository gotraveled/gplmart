# Ad creative at scale - copy, briefs and test matrices

Turn one product + audience into a full creative testing system: multiple copy angles, headline
variants, visual briefs for designers/generators, and a structured A/B matrix. The output is a
campaign kit a media buyer can launch immediately.

No image/video generation here - this skill writes the WORDS and the CREATIVE DIRECTION.

---

## Intake - one batch

1. Product name + what it does + price point
2. Target audience (who buys it, their pain/desire in their words)
3. Platform: Meta feed / Reels / Stories / TikTok (affects length and hook style)
4. Offer: discount, free shipping, bundle, or none
5. Top 3 claims/proof points (verbatim from product page if possible)
6. Brand voice: playful / premium / urgent / friendly / technical
7. Any compliance constraints? (health claims, financial, kids products - extra care needed)

## The creative system

For each product, generate THREE angles - never just one:

| Angle | Hook style | Best for |
|---|---|---|
| **Problem-solution** | "Tired of [pain]?" | Cold traffic, problem-aware audiences |
| **Curiosity/desire** | "Wait till you see this" / "Nobody talks about..." | Broad audiences, impulse products |
| **Offer/proof** | "50% off ends tonight" / "10,000+ sold" | Retargeting, warm audiences, launches |

Each angle gets: 3 primary text variants, 3 headlines, 1 creative brief (what the image/video
should show), and a suggested CTA button.

## Output format - the campaign kit

```
PRODUCT: [name]
AUDIENCE: [who]
OFFER: [terms]

ANGLE 1 - Problem-solution
  Primary texts: [3 variants, <125 chars each for feed, <40 for stories]
  Headlines: [3 variants, <40 chars]
  Creative brief: [shot list / visual direction for designer or generator]
  CTA: Shop Now / Learn More / Get Offer

ANGLE 2 - Curiosity
  ...
ANGLE 3 - Offer/proof
  ...

TEST MATRIX:
  Ad set A: Angle 1 x Creative variant 1
  Ad set B: Angle 2 x Creative variant 1
  Ad set C: Angle 3 x Creative variant 1
  (scale winner to x3 creative variants next round)
```

## Copy rules that matter

- First line is the hook - it must work WITHOUT the image (many users read before they look)
- Match the audience's vocabulary - "molgj" not "moisture", "dad ka" not "paternal" (for Indian audiences)
- Numbers beat adjectives: "cuts cooking time 50%" > "amazing time saver"
- One idea per ad - stacked claims confuse and reduce CTR
- No fake urgency unless real; no unverifiable superlatives ("best in world" = ad account risk)
- Emojis: max 1-2, only if brand voice allows - they hurt premium positioning
- Always write the DISLIKE test: would YOU stop scrolling for this? If not, rewrite the hook

## The test discipline

- Launch 3 angles x 1 creative each = 3 ads minimum per product
- Budget: equal split, $20-50/day total for testing
- Judge at $100-150 spend per ad - CTR >1% + add-to-cart or purchase = winner signal
- Winner gets 3 NEW creative variants (same copy angle, different visuals) - never just scale the same ad forever
- Kill losers at day 3-5, don't "give them more time"
