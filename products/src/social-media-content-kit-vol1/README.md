# Social Media Content Kit Vol. 1 — Ecommerce Edition

Ready-to-post swipe files for Shopify and DTC store owners. Every file is copy-paste copy — replace `[PRODUCT]` and `[BRAND]` with your own and post.

## File List

| File | Contents |
|------|----------|
| `book.md` | The full guide: 30-day rollout plan, caption formulas, hooks, content calendar, hashtag strategy, story/highlight system, DM templates, metrics checklist. |
| `captions.csv` | 150+ ready captions across 6 categories: educational, social-proof, behind-scenes, promo, engagement, story. Columns: `category,platform,caption`. |
| `hooks.csv` | 190+ opening hooks for TikTok, Reels, Shorts, and YouTube Shorts. Columns: `platform,hook`. |
| `hashtags.csv` | 6 hashtag banks of 30 tags each: ecommerce-general, fashion, home-decor, beauty, fitness, handmade. Columns: `set,size,tags`. |
| `calendar.csv` | The 30-day content calendar as data. Columns: `day,theme,format,caption_category,cta`. |

## Quick Start

1. **Read `book.md`** for the strategy — the 4-week arc (educate → prove → offer → community) and the weekly review checklist.
2. **Open `captions.csv`** and filter to the category you need. Pick a caption, swap in `[PRODUCT]`/`[BRAND]`, delete lines that don't fit.
3. **Pick a hook** from `hooks.csv` for the first 1–3 seconds of your Reel/TikTok, then add the caption.
4. **Grab a hashtag set** from `hashtags.csv` matching your niche. Rotate sets weekly; keep your own branded tag in every post.
5. **Follow `calendar.csv`** for what to post each day.

## Tips

- Batch-create captions on Sunday; don't write them daily.
- Every promo caption should end with a question disguised as urgency.
- Track saves and comments — those are the metrics that predict sales, not likes.
- Adapt freely: these are written for ecommerce/DTC but work for any product brand.
