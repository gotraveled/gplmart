# Content quality checklist

## Before posting

- [ ] Post fits one content pillar (not random)
- [ ] Caption has hook in first line
- [ ] CTA is clear (link, comment, share, save)
- [ ] Hashtags relevant and rotated (not same set every time)
- [ ] Visual quality good (good lighting, clear product, clean background)
- [ ] Mobile-readable (text overlays large enough, captions scannable)

## Platform-specific

**Instagram**:
- [ ] Feed post: 1080x1080 or 1080x1350
- [ ] Story: 1080x1920, safe zones respected
- [ ] Reel: hook in first 3 seconds, text overlays, trending audio

**Facebook**:
- [ ] Image/video optimized for feed
- [ ] Caption under 2,000 chars
- [ ] Link included if relevant

**TikTok**:
- [ ] Hook in first 1-3 seconds
- [ ] Trending sound used (if applicable)
- [ ] Text overlays for silent viewing
- [ ] CTA at end

**Pinterest**:
- [ ] Vertical image (2:3 ratio)
- [ ] Keyword-rich description
- [ ] Link to product page

**WhatsApp Status**:
- [ ] Under 30 seconds
- [ ] Clear offer/product visible
- [ ] Posted during peak hours

## Engagement

- [ ] Responded to comments within 1 hour of posting
- [ ] Replied to DMs
- [ ] Engaged with 5-10 relevant accounts daily
- [ ] Stories posted throughout the day

## Weekly review

- [ ] Checked which posts performed best
- [ ] Noted what didn't work (and why)
- [ ] Adjusted next week's plan accordingly
- [ ] Saved high-performing content for reuse
