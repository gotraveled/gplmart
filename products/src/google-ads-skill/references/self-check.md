# Launch readiness checklist

## Before launch

### Account setup
- [ ] Google Ads account created, billing set up
- [ ] Google Merchant Center verified (for Shopping/PMax)
- [ ] Product feed connected and error-free
- [ ] Conversion tracking installed and TESTED (test purchase works)
- [ ] Google Analytics linked (optional but recommended)

### Campaign structure
- [ ] Campaigns segmented by goal (brand, non-brand, shopping, remarketing)
- [ ] Ad groups tightly themed (5-15 keywords each)
- [ ] Negative keywords added (universal + category-specific)
- [ ] Budget allocated by funnel stage
- [ ] Bidding strategy appropriate for conversion volume

### Creative/assets
- [ ] RSA headlines written (15 headlines, 4 descriptions)
- [ ] Ad copy matches landing page promise
- [ ] Product images high-quality (white bg, high-res)
- [ ] Extensions added (sitelinks, callouts, structured snippets)
- [ ] Promotion extensions for current offers

### Tracking
- [ ] Conversion actions defined (purchase, add to cart, lead)
- [ ] Conversion values set (actual order values, not flat)
- [ ] Enhanced conversions enabled (better attribution)
- [ ] Call tracking if phone orders matter

## First 48 hours

- [ ] Ads approved (check policy status)
- [ ] Impressions coming in (if zero, check targeting/budget)
- [ ] Clicks at expected CPC range
- [ ] No disapproved products in Shopping
- [ ] Search terms report showing relevant queries

## Week 1 review

- [ ] Search terms cleaned (negatives added)
- [ ] Underperforming ads paused
- [ ] Budget pacing on track
- [ ] Conversion tracking verified (real purchases showing)
- [ ] ROAS/CPA within acceptable range OR diagnosed why not
