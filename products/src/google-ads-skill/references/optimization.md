# Optimization rhythm - daily, weekly, monthly

## Daily (5 minutes)

- Check: spend, conversions, CPA/ROAS vs target
- Check: disapproved ads or policy issues
- Check: budget pacing (won't run out mid-day)
- Action: pause bleeding campaigns, approve good ones

## Weekly (30 minutes)

### Search terms report (most important)

1. Export search terms report
2. Sort by cost descending
3. Converting queries → add as exact match keywords
4. Irrelevant queries → add as negative keywords
5. High-spend zero-conversion → investigate (ad copy? landing page?)

### Ad performance review

- Which ads have best CTR? → create more like them
- Which ads have worst CTR? → pause or rewrite
- Which keywords have best conversion rate? → increase bids
- Which keywords have worst conversion rate? → decrease bids or pause

### Feed/asset check (Shopping/PMax)

- Any disapproved products? → fix feed issues
- Any out-of-stock products still running? → pause them
- Image quality issues? → update feed
- Price mismatches? → fix immediately (Google penalizes)

## Monthly (2 hours)

### Full performance review

- ROAS by campaign, ad group, product
- Budget reallocation: shift from underperformers to winners
- Search query analysis: new keyword opportunities
- Competitor check: are they running ads? on what terms?

### Strategic adjustments

- Seasonality: upcoming festivals/sales = budget increases
- Product lifecycle: new products = test budget, winners = scale
- Margin analysis: which products are actually profitable after ad spend?
- Landing page review: are product pages converting as well as they could?

### Account hygiene

- Remove/archived old campaigns
- Update ad copy that's been running 60+ days (ad fatigue)
- Review audience lists for remarketing
- Check conversion tracking accuracy (test purchase)

## The metrics that matter (in order)

1. **ROAS** (revenue / ad spend) - the only metric that pays bills
2. **CPA** (cost per acquisition) - must be below your margin
3. **Conversion rate** - landing page + offer quality signal
4. **CTR** - ad relevance signal
5. **Quality Score** - Google rewards good ads with cheaper clicks
6. **Impression share** - are you showing for all relevant searches?
