# Negative keywords - the money savers

## Universal negatives (every ecommerce account)

```
free, cheap, DIY, how to make, jobs, career, salary, course, tutorial,
images, pictures, wallpaper, vector, clipart, mockup, PSD, font,
repair, second hand, used, rent, wholesale, supplier, manufacturer,
dropship, franchise, buy in bulk, sample, prototype
```

## Category-specific negatives

### Kitchen/home products
```
dishwasher safe test, microwave safe test, induction compatible check,
replacement parts, spare parts, warranty claim, service center
```

### Fashion/apparel
```
stitching, tailoring, alter, custom size, bulk order, reseller,
dropshipping, manufacturer, wholesale price
```

### Electronics
```
specifications pdf, user manual, drivers, firmware update,
repair guide, circuit diagram, datasheet
```

### Beauty/personal care
```
side effects, ingredients list,Expiry date check, dermatologist review,
chemical free certification
```

## Competitor negatives (careful)

Only add if you're NOT bidding on competitor terms:
```
[competitor brand name]  (if you don't want their traffic)
```

If you ARE bidding on competitor terms, don't negative them.

## Search terms report workflow (weekly)

1. Go to Search Terms report
2. Sort by cost (highest spend first)
3. For each query: converting? → add as keyword. Not relevant? → add as negative.
4. Look for patterns: "near me", "open now", "jobs" = likely irrelevant
5. Add negatives at CAMPAIGN level (applies to all ad groups)

## The cost of NOT having negatives

Example: lunch box seller without negatives gets clicks for:
- "lunch box recipe" (wanted cooking content)
- "lunch box drawing" (wanted art)
- "lunch box jobs" (wanted employment)
- "free lunch box" (wanted free stuff)

Each irrelevant click = wasted budget. 20% waste on ₹10,000/month = ₹2,000 gone.
