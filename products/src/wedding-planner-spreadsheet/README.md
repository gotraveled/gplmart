# Wedding Planner Spreadsheet System

The spreadsheet that out-sold every printable wedding planner on Etsy - budget, guests, timeline, seating, vendors and checklist with live formulas.

## What's inside
- **Wedding-Planner-Spreadsheet-System.xlsx** - 6 tabs:
  - *Budget* - estimated vs actual per category, variance and totals live
  - *Guest List* - RSVPs, meal choice, plus-ones, table assignments + RSVP counts
  - *Timeline* - countdown tasks by deadline with status dropdowns
  - *Seating Plan* - tables, capacity and guest names with seats-left check
  - *Vendors* - quotes, deposits, balances, status
  - *Checklist* - the complete pre-wedding task list by months-out

## How to use
Open in Excel, Google Sheets (File > Import) or Numbers. Yellow cells are inputs; everything calculates. Make a copy per wedding/event.
