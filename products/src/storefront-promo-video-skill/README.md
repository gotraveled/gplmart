# Storefront Promo Video Skill

An AI-agent skill bundle for short brand/storefront promo videos - hero shots, product range, brand mood and a call-to-action end card. Generated via Higgsfield/fal.ai with a Remotion finishing pass for logo, fade and audio.

## What's inside

- `SKILL.md` - the skill definition (drop into Claude Code / any skill-compatible agent)
- `references/` - intake question bank + spec schema, shot grammar & pacing, provider mechanics & costs, finishing pass, pre-delivery checklist

## Pair it with

The **Ecom Product Video Skill** (sibling product) handles single-product films; this one handles store-level promos. Same provider setup, same cost discipline.

## Requirements

- A skill-compatible AI agent (Claude Code or equivalent)
- A generation provider account: Higgsfield or fal.ai (paid per generation)
- Node.js for the finishing scripts
