# Pre-delivery self-check

- [ ] Duration matches request (within 0.5s)
- [ ] Aspect ratio correct (verify actual file dimensions, not assumptions)
- [ ] Every claim on screen is verbatim store copy
- [ ] Logo is the real file, only in end card
- [ ] No generated logos/watermarks mid-film
- [ ] CTA text matches spec exactly
- [ ] Audio (if supplied) present and not clipping
- [ ] Watched the WHOLE film once on a phone-sized preview
- [ ] No shot repeats another shot's action or camera move
