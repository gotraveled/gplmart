# Free tools per audit layer

## Technical
- **Google PageSpeed Insights** - Core Web Vitals, free, no signup
- **Google Rich Results Test** - structured data validation
- **Google Search Console** - indexing, coverage, manual actions (user must provide access)
- **Screaming Frog** (free up to 500 URLs) - full crawl, duplicates, redirects
- **XML-sitemap validators** - check sitemap health
- **Mobile-Friendly Test** - Google official

## On-page
- **Meta tag preview tools** - check title/description truncation
- **Heading structure analyzers** - browser extensions
- **Grammarly/LanguageTool** - readability signals

## Content & intent
- **Google autocomplete + PAA** - real query discovery, free
- **AnswerThePublic** - question-format content ideas
- **Google Trends** - demand validation
- **AlsoAsked / AnswerSocrates** - PAA expansion

## Competitive
- **Ahrefs free backlink checker** - limited but useful
- **Ubersuggest free tier** - keyword difficulty estimates
- **SimilarWeb free** - traffic estimates (rough)

## Shopify-specific
- **Theme code editor** - check title/meta templates directly
- **Duplicate content checkers** - Copyscape free tier
- **Google "site:domain.com"** - see what's actually indexed
