# Shopify Store Launch Document Pack

Ready-to-customize legal and business documents for new Shopify stores.

## What's Inside

| File | Description |
|---|---|
| `privacy-policy.md` | Complete privacy policy template (GDPR/CCPA/DPDPA-aware) |
| `refund-policy.md` | Refund & return policy for physical + digital products |
| `shipping-policy.md` | Shipping policy with India + international coverage |
| `terms-of-service.md` | Store terms & conditions with IP and liability clauses |
| `faq-template.md` | 35+ FAQ Q&As covering shipping, payments, returns, products |
| `email-templates.md` | 9 ready email templates (order, shipping, reviews, cart, wholesale) |
| `book.md` | The guide: why these docs matter + how to use them |

## How to Use

1. **Download** all files
2. **Customize** each file — replace every `[BRACKETED]` placeholder with your store's real info
3. **Publish** to Shopify:
   - Policies → Shopify admin > Settings > Policies
   - FAQ → Online Store > Pages > Add page
   - Emails → Settings > Notifications or your email marketing app
4. **Review** HTML comments in each file for customization tips

## Key Features

- ✅ Written specifically for Shopify/D2C sellers
- ✅ Mentions Shopify checkout, apps, digital products
- ✅ Fill-in `[BRACKETED]` placeholders throughout
- ✅ Ready-to-paste email templates
- ✅ Legal-style language, not lorem ipsum
- ✅ HTML comments guide customization

## Requirements

- Shopify store (or any e-commerce platform)
- Basic understanding of your business details (shipping times, return policy, contact info)
