# Freelance Proposal Templates — 8 Ready-to-Adapt Versions

Each template below has a complete structure: **subject line → opening hook → understanding of need → proof points → scope → timeline → pricing anchor → CTA → follow-up bump**. Fill the `[BRACKETS]`, delete what doesn't apply, and tailor the hook to something specific about the client's business. Never send these unedited — an unfilled template is the fastest way to lose a job.

---

## How to use these

1. Pick the template closest to the job.
2. Rewrite the **subject line** and **first two sentences** — these decide whether the rest gets read.
3. Replace every `[BRACKET]` with real detail. If you have no real detail, don't fake it — use the structure and honest proof.
4. Keep total length under ~350 words. Busy founders skim.
5. End with ONE call to action — a question or a small free deliverable, not "let's schedule a call."
6. Save each version you send (with the client's name) so follow-ups can reference it.
