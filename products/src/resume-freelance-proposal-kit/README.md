# Resume & Freelance Proposal Kit

A copy-paste template kit for freelancers who want clients — modern, ATS-friendly markdown resumes, proposal templates that get replies, and cover letters for every situation. No design skills needed: clean structure does the work.

## What's inside

| File | What it is |
|---|---|
| `book.md` | The complete guide — variant selection, the 6-second rule, ATS + human tailoring, quantifying achievements, proposal structure, rate anchoring, follow-up cadence, platform tips (Upwork/LinkedIn/direct outreach), and before/after bullet examples. |
| `resume-01-tech-general.md` | Software developer / full-stack resume template |
| `resume-02-ecommerce-shopify.md` | Shopify developer / Liquid expert resume template |
| `resume-03-digital-marketer-meta-ads.md` | Performance marketer / Meta ads resume template |
| `resume-04-graphic-designer-brand.md` | Graphic designer / brand identity resume template |
| `resume-05-content-writer-copywriter.md` | Content writer / copywriter resume template |
| `resume-06-ecommerce-dropshipping-operator.md` | E-commerce / dropshipping operator resume template |
| `proposals.md` | 8 proposal templates — web design, Shopify build, Meta ads, logo/branding, content writing, virtual assistant, video editing, consulting retainer. Each includes subject line, hook, need paragraph, proof, scope, timeline, pricing anchor, CTA, and follow-up bump. |
| `cover-letters.md` | 5 cover letter templates — cold application, referral, after portfolio piece, responding to job post, re-engaging past client. |

## How to use

1. **Pick your variant** — match the resume template to the kind of client you're targeting (guide has a decision table).
2. **Copy the markdown** into any plain-text editor.
3. **Fill every `[BRACKET]`** — delete placeholder brackets, write real details. Never send a template with brackets still in it.
4. **Paste into Google Docs, Microsoft Word, or Notion** — markdown headings/bullets import cleanly; or paste into Typora/MarkText and export PDF directly.
5. **Export as PDF** — use a clean sans-serif font (Inter, Helvetica, Arial), single column, standard section headers so ATS can parse it. Name the file `Firstname-Lastname-Role.pdf`.
6. **Tailor per application** — the 15-minute checklist in `book.md` Section 5: mirror keywords, reorder bullets, swap skills.
7. **Pair with a proposal** — match the proposal template to the job type, rewrite the first two sentences for the specific client, and schedule follow-ups on days 3, 7, and 14.
