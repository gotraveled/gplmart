# Recovery flows - turn returns into repeat customers

## The psychology

A customer who returns an item is NOT lost - they're a customer who had a problem. How you handle
the return determines whether they buy again, leave a review, or tell friends.

## Immediate post-return (day of resolution)

```
"Hi [Name], your return for order #[number] has been processed.
Refund of ₹[amount] will reach you in [5-7] business days.

We'd love to know what went wrong - your feedback helps us improve.
What made you return the [product]?"
```

This message: confirms resolution, sets timeline, opens feedback channel, keeps door open.

## Win-back sequence (7-14 days after refund)

**Email/WhatsApp 1**: "We miss you! Here's 10% off your next order - code WELCOME10. New arrivals you might like: [link]"

**Email/WhatsApp 2** (7 days later): "Still thinking about [product category]? These are our bestsellers right now: [link]"

**Email/WhatsApp 3** (14 days later): "Last chance for your 10% off - expires [date]. Or check our new collection: [link]"

## Exchange-first strategy

When possible, offer exchange BEFORE refund:

- Size exchange: "Want to try a different size? We'll ship it first, you return the original after."
- Colour/style exchange: same logic
- Upgrade exchange: "The [product] you returned has an upgraded version - want to try it at same price?"

Exchange keeps revenue in-house AND gives the product a second chance.

## Feedback loop (feed return data into product decisions)

Monthly review of return reasons:
- "Too small" appearing on specific product → update size guide, add model stats
- "Not as pictured" → reshoot photos, rewrite description
- "Defective" → QC issue with supplier, switch supplier or add inspection
- "Changed mind" → product-market fit issue, consider discontinuing or repositioning

## Metrics to track

- Return rate by product (identify problem products)
- Return rate by reason (identify fixable causes)
- Exchange vs refund ratio (higher exchange = better recovery)
- Post-return repurchase rate (measure win-back success)
- Time to resolution (faster = happier customers)
