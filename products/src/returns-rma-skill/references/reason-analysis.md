# Return reason tracking + fixes

## Setup

Every return needs a reason code. Train your team/VA to classify:

| Code | Reason | Sub-reason |
|---|---|---|
| SIZE | Doesn't fit | Too small / too big / wrong size chart |
| QUALITY | Defective/damaged | Arrived broken / stopped working / poor quality |
| EXPECTATION | Not as described | Different colour / smaller than expected / missing features |
| MIND | Changed mind | No longer needed / found cheaper / gift issue |
| WRONG | Wrong item sent | Different product / missing item / quantity wrong |
| FRAUD | Suspicious | Empty box / worn item / serial returner |

## Fix mapping

| Return reason spike | Root cause | Fix |
|---|---|---|
| Size returns on one product | Bad size chart | Update size guide, add model measurements |
| "Not as pictured" | Misleading photos | Reshoot with real product, add video |
| "Defective" from one supplier | Quality drop | Switch supplier, add QC inspection |
| Wrong item | Pick/pack error | Barcode scanning, double-check process |
| Changed mind spike | Weak product-market fit | Review if product should stay, improve description |
| Fraud spike | New fraud pattern | Tighten verification, flag customers |

## Industry benchmarks (India ecommerce)

- Fashion/apparel: 20-30% return rate (normal - sizing issues)
- Electronics: 5-10% (lower - higher consideration)
- Home/kitchen: 8-15%
- Beauty/personal care: 5-8% (low - repeat purchase driven)
- Grocery/food: 2-5% (perishables, but quality complaints matter)

Above benchmark = fixable problem. Below = you're doing something right - document it.
