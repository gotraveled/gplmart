# Return policy template

## Copy-paste template

```
RETURNS & EXCHANGES POLICY

We want you to love your purchase. If something isn't right, we're here to help.

ELIGIBILITY:
- Returns accepted within [7/15/30] days of delivery
- Item must be unused, with tags attached and original packaging
- Non-returnable: intimate items, personalized products, opened electronics, sale items marked "final sale"

HOW TO INITIATE:
- WhatsApp: [number] - fastest response
- Email: [email] with order number
- Portal: [link if applicable]

PROCESS:
1. Contact us within the return window
2. We'll approve and share return instructions within 24 hours
3. Pack item securely with all tags and accessories
4. Drop at [courier partner] or schedule pickup
5. We inspect within 48 hours of receipt
6. Refund processed within [5-7] business days to original payment method

WHO PAYS RETURN SHIPPING:
- Change of mind / wrong size: customer pays (we share cheapest option)
- Defective / damaged / wrong item: we pay (prepaid label provided)

REFUND METHOD:
- Original payment method only (no store credit unless you choose it)
- COD orders: bank transfer or UPI after verification

EXCHANGES:
- Size exchanges free for [clothing/footwear] - we ship replacement first
- Other exchanges: return + reorder at current price

DAMAGED/DEFECTIVE ITEMS:
- Report within 48 hours of delivery with photos/video
- We replace or refund - your choice
- No return shipping cost to you

FRAUD PREVENTION:
- Items must be returned in original condition with all tags
- Worn, washed, or damaged items may be rejected or partial refund given
- We reserve the right to refuse returns with suspicious patterns

QUESTIONS? WhatsApp us: [number] - real humans, fast replies.
```

## Policy design decisions

| Decision | Aggressive (more sales) | Conservative (less returns) |
|---|---|---|
| Window | 30 days | 7 days |
| Who pays | Store pays all | Customer pays change-of-mind |
| Condition | "Like new" loose | Tags + packaging strict |
| Refund speed | 3 days | 7-10 days |
| Exchanges | Free size swap | Return + reorder |

Test: start generous (30 days, store pays for defects), tighten only if fraud/abuse appears.
