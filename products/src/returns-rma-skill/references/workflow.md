# Return workflow - step by step

## The flow

```
INITIATE → VERIFY → APPROVE → PICKUP → RECEIVE → INSPECT → RESOLVE → FOLLOW-UP
```

### 1. Initiation (customer contacts you)

Channels: WhatsApp (preferred - fastest), email, portal

What to collect:
- Order number
- Item + reason for return
- Photos if damage/defect claimed
- Preferred resolution (refund/exchange)

Response time target: under 2 hours during business hours.

### 2. Verification

Check:
- Order exists and is within return window
- Item is returnable (not in non-returnable category)
- Reason matches policy (defect = store pays, change-of-mind = customer pays)
- Customer return history (first-time vs serial returner)

### 3. Approval

- Auto-approve if: eligible + first return + reason fits policy
- Manual review if: serial returner + high-value item + suspicious reason + damage claim without photos

### 4. Pickup/drop-off

- Store pays (defect/wrong item): send prepaid courier label or schedule pickup
- Customer pays (change of mind): share cheapest courier option, customer books
- Customer drop-off: give address + timing, confirm receipt

### 4. Receive & inspect

On receipt:
- Verify item matches order (SKU check - prevent price switching)
- Check condition: unused vs worn vs damaged vs wrong item
- Weigh/package check (empty box detection)
- Photograph condition for records

### 5. Resolve

- **Refund**: process to original payment method, timeline 5-7 business days
- **Exchange**: ship replacement first (for size exchanges), then process return
- **Reject**: if outside policy or fraud suspected - explain clearly, offer partial resolution if reasonable

### 6. Follow-up

- Confirmation message: "Refund of ₹X processed, expect in 5-7 days"
- Feedback request: "What made you return? Helps us improve" (optional, don't push)
- Win-back: "Sorry it didn't work - here's 10% off next order" (after 7-14 days)

## Response templates

**Approval**: "Your return for order #[number] is approved. Return shipping [prepaid label/customer pays ₹X]. Drop at [address] by [date]."

**Rejection**: "Unfortunately this return doesn't qualify because [reason]. Per our policy, [explanation]. If you believe this is an error, reply with photos and we'll review."

**Damage claim**: "Sorry to hear that! Please send photos of the item and packaging within 48 hours. We'll arrange replacement/refund immediately - no return needed."
