# Returns system audit checklist

## Policy
- [ ] Written policy exists and is easily accessible (footer, product pages, WhatsApp away)
- [ ] Policy covers: window, condition, who pays, process, refund method, non-returnables
- [ ] Non-returnable categories clearly disclosed at purchase
- [ ] Policy language is clear, not legal-jargon

## Prevention
- [ ] Size guides on all fashion/apparel products
- [ ] Accurate product photos (real product, multiple angles)
- [ ] Product videos where helpful (how it works, scale, texture)
- [ ] Detailed descriptions with specs, dimensions, materials
- [ ] FAQ section addressing common pre-purchase questions

## Workflow
- [ ] Clear initiation channel (WhatsApp/email/portal)
- [ ] Response time target set (<2 hours business hours)
- [ ] Return status tracking (customer can check progress)
- [ ] Inspection process defined (condition check, SKU verify)
- [ ] Refund timeline communicated upfront

## Fraud prevention
- [ ] Return history tracked per customer
- [ ] Damage claims require photos/video
- [ ] SKU verification on returned items
- [ ] Weight check for high-value returns
- [ ] Serial returner flagging (>30% rate)

## Recovery
- [ ] Post-return follow-up message sent
- [ ] Win-back sequence triggered automatically
- [ ] Exchange option offered before refund where possible
- [ ] Return reason data collected and reviewed monthly
- [ ] Feedback incorporated into product pages

## Metrics
- [ ] Return rate tracked by product, reason, customer
- [ ] Return rate by reason reviewed monthly
- [ ] Exchange vs refund ratio tracked
- [ ] Post-return repurchase rate measured
- [ ] Time to resolution measured and improving
