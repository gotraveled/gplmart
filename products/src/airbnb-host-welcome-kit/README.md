# The Airbnb Host Welcome Kit

The printed touches that turn guests into 5-star reviews: welcome note, guest book, house manual, local guide, review request card and emergency card.

## What's inside
- **Airbnb-Host-Welcome-Kit.pdf**:
  - Welcome note card template
  - Guest book (2 pages of lined entries)
  - Complete house manual template (WiFi, lock, rules, kitchen, emergency)
  - Local guide template (2 pages of fill-in picks)
  - Review request card
  - Emergency info card

## How to use
Print at 100% / Actual Size on card stock. Fill every [BRACKET] once, print a stack, keep at the property.
